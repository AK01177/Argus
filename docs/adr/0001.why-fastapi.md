
# 1. Why FastAPI

Date: 2026-08-25

## Status

Accepted

## Context

Argus requires a backend framework capable of handling asynchronous tasks, high-performance API routing, and AI workloads. The Phase 1 and Phase 2 roadmap involves heavy data ingestion (shallow cloning Git repositories, AST parsing) and integration with GenAI providers. We need a framework that is easy to write, heavily typed, and supports fast asynchronous I/O out of the box.

## Decision

We chose **FastAPI** as the core backend web framework.

## Consequences

**Pros:**

- **Asynchronous by Default:** Native `async/await` support is perfect for calling external LLM APIs and navigating the file system asynchronously.
- **Pydantic Validation:** Type hints and automatic data validation make the codebase extremely robust and reduce runtime errors.
- **Auto-generated Documentation:** The automatic `/docs` (Swagger UI) allows for instant testing of endpoints without writing external postman collections.

**Cons:**

- Python is slower than compiled languages like Go, but the bottleneck for our application is network I/O (LLM API calls) and database reads, not CPU compute (and we will offload AST parsing to fast C-bindings via tree-sitter).
